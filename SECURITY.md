# Security policy

Please report a vulnerability privately, not in a public issue: use GitHub's
**Report a vulnerability** button on this repository's Security tab, or email
**hello@simplyboost.io**. We reply within two working days.

Include the package and version, what an attacker can do, and steps to reproduce.

Never post an identity secret in an issue, a pull request or a log. If one has been exposed,
rotate it in the SimplyBoost dashboard (Install → Identity verification).
