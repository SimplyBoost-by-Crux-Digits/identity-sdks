# Contributing

Run the tests for each package:

```bash
composer install && vendor/bin/phpunit          # PHP + Laravel
cd node && npm ci && npm test                   # Node.js
cd python && python -m unittest discover -s tests   # Python (PYTHONPATH=src, or pip install -e .)
```

## The signing rule is fixed

The packages must produce exactly what the SimplyBoost server verifies. `test-vectors.json` is
generated by the server's own `compute_widget_hmac`; never edit it by hand. A change to the rule
starts on the server, and its new vectors are copied here.

## Releasing (maintainers)

The three packages share one version.

1. Set the version in `node/package.json`, `python/pyproject.toml` and
   `python/src/simplyboost_identity/__init__.py`, and move `[Unreleased]` in `CHANGELOG.md`.
2. Merge to `main`, then push a tag `vX.Y.Z`.
3. The Release workflow tests everything, checks the versions match the tag, builds the npm and
   Python packages, and waits for approval in the `release` environment before publishing.
   Packagist picks up the tag from GitHub on its own.
