# Changelog

All three packages (`simplyboost/identity`, `@simplyboost/identity`, `simplyboost-identity`)
share one version number and are released together from one tag.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and
[Semantic Versioning](https://semver.org/).

## [Unreleased]

## [1.0.0]

### Added

- Signing helpers that produce exactly the `user_hash` the SimplyBoost server verifies
  (`HMAC_SHA256(secret, lower(strip(email)) + ":" + ts)`, hex), with the server's own whitespace
  rule, in PHP, Node.js and Python.
- `visitor()` (the four values the widget needs) and a widget snippet helper that escapes every
  value for the `<script>` element and supports a CSP nonce.
- Laravel integration: auto-discovered service provider, `config/simplyboost.php`,
  `<x-simplyboost-widget />`, `@simplyboostWidget`, and the `GET /simplyboost/identity` refresh
  route for pages left open longer than the 10-minute window.
- Node.js: TypeScript types, ESM and CommonJS builds; Express and Next.js examples.
- Python: typed package; Django and Flask examples.
- Shared test vectors generated by the SimplyBoost server, checked by every package's tests.
